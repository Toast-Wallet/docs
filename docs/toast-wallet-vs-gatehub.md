Both were popular XRP-focused wallets from the same early XRP Ledger era, but they're built
differently and only one of them is still actively maintained.

**Toast Wallet:** open-source, non-custodial, mobile/desktop app. Discontinued since 2020.
Simple by design — it does one thing (store and move XRP) and does not include trading, multi-asset
support, or built-in exchange features.

**Gatehub:** also non-custodial at its core, but built more as a broader XRP Ledger platform —
supports multiple assets on the ledger (not just XRP), includes some trading/exchange
functionality, and has continued active development.

**If you're deciding where to move funds out of an old Toast Wallet:**
- Choose **Gatehub** if you want more built-in functionality (trading, multi-asset support) in one
  place, and don't mind a slightly more complex interface.
- Choose **Xaman** (our default recommendation — see our
  [full migration guide](./migrate-toast-wallet-to-xaman.md)) if you want the simplest, most
  widely-supported modern equivalent to what Toast Wallet used to be.
- Choose a **hardware wallet** (see our
  [comparison with Ledger Nano S](./toast-wallet-vs-ledger-nano-s.md)) if security for
  long-term holding matters more to you than day-to-day convenience.

**Neither Gatehub nor any other software wallet solves the underlying recovery problem** if you're
still locked out of your old Toast Wallet — that has to happen first. See our
[full recovery guide](./how-to-recover-xrp-toast-wallet.md) before deciding where to move funds
to.

## ⚠️ Known Scams — Do Not Use These

- **The "Toast Plus" fraudulent app** (App Store / Google Play, package `co.peninsulasoftware.toastwallet`) — a lookalike app, not affiliated with Toast Wallet, that has stolen an estimated **$5M+ in XRP**. Full details: [The Toast Plus App Scam](./toast-plus-app-scam.md).
- **The toastwallet.app phishing site** — a clone of the official recovery page that drains any wallet imported into it. Full details: [Toast Wallet Phishing Sites](./toast-wallet-phishing-sites.md).
- **Marketing clone sites** — `xrp-toastwallet.com`, `toast-wallet.com`, `en-toastwallet.com`, `toast-wallet.net`. Not official, and misrepresent how Toast Wallet actually works.
- **Paid "recovery service" DMs** — always a follow-up scam; no one can reverse an XRP Ledger transaction.

See the [full Toast Wallet scam warning list](./toast-wallet-scam-warning-list.md). If you believe you've been scammed, file a report at [ic3.gov](https://www.ic3.gov).
